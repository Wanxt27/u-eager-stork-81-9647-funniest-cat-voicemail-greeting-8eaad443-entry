`main.ts` (Node 22, stdlib only) writes a single voicemail greeting recorded by a cat — one line, 118 characters — to `/output/entry.txt`:

> You've reached Mittens. I'm asleep on your keyboard — leave a message after the beep, and I'll delete it with my butt.

Run it with:

```sh
node main.ts
```
